# 🚀 Personal Portfolio Website | Saidur Rahman

Welcome to the official repository for my personal portfolio website! This project showcases my academic profile, key skills, software projects, hobbies, and contact information in an interactive, responsive dark-themed dashboard layout.

---

## 🌟 Features

* **Interactive Navigation:** Smooth dynamic tab switching for home, education, and contact views without page reloads.
* **Modern UI Design:** Clean glassmorphism layout, custom icons, and sleek dark-mode aesthetics.
* **Education Section:** Highlights academic milestones including HSC (Chattogram College) & SSC (Chattogram Government High School).
* **Responsive Layout:** Works smoothly across both desktop (16:9 aspect ratio optimized) and mobile devices.
* **Contact Form:** Integrated message box with direct contact information.

---

## 🛠️ Built With

* **HTML5** - Page structure and semantically organized content.
* **CSS3** - Custom styling, CSS Grid, Flexbox, glassmorphism visual effects, and animations.
* **JavaScript (ES6)** - Tab management, dynamic routing, and interactive form handling.
* **FontAwesome** - Modern vector icons for tech skills, hobbies, and social links.
